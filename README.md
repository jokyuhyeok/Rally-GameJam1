오락실에서 볼 수 있던 아케이드 게임이다.
뒤쫓아오는 차를 피해서 맵에 흩어져 있는 모든 깃발을 모아 하이스코어를 기록하자.

한국에서는 "방구차"라는 이름으로 알려져있다.
이 게임의 BGM이 유명한데, 
사다리타기를 할 때마다 부르게 되는 BGM이 이 게임에서 나온 것이다.
